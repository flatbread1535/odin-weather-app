# Odin Weather App

This project was created or the Odin Project with the purpose of building a very basic weather app. This project was mainly focused on using asynchronous JavaScript and APIs.

## This poject contains

- A navbar with a search box where a user can search for weather locations.
- A main content section with a tab that pops up containing weather information for the location.

## Concepts used for this project

- Previous HTML/CSS concepts
- JavaScript classes and factory functions
- DOM rendering with JavaScript
- ES6 Modules, Import/Export
- npm, package.json
- Bundling with Webpack
- Loading HTML, CSS
- OOP principles
- ESLint, Prettier
- Form validation with JavaScript (Constraint Validaiton API)
- Working with APIs, fetch
- Promises
- async/await
